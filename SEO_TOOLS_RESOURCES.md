## 🚨 RED FLAGS TO MONITOR

### Warning Signs (Fix immediately)
```
❌ Sudden drop in impressions (> 20%)
   → Check: Indexing status in GSC
   → Check: Manual actions in GSC
   → Check: Robot.txt not blocking

❌ CTR dropping for top pages
   → Rewrite meta title
   → Check: Google showing old snippet
   → Request indexing update

❌ Lighthouse score dropping
   → Check: New slow code added?
   → Check: Images not optimized?
   → Run: Performance audit

❌ Getting 404 errors in GSC
   → Check: Broken internal links
   → Check: Old pages deleted
   → Setup: 301 redirects

❌ Too many crawl errors
   → Check: XML sitemap valid
   → Fix: Broken images/CSS
   → Resubmit sitemap in GSC
```
